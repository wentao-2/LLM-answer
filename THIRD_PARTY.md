# External materials

The published experimental code and wrappers are distributed under the existing
repository MIT license. No model weight or font file is redistributed here.

External checkpoint licenses apply to separately downloaded weights, including
the official Qwen, Microsoft Phi, Mistral and OLMo releases named in the recorded
configurations. The source configurations and evidence inventories identify
their exact revisions where recovered. A model name alone does not establish
a historical weight revision.

NumPy, Matplotlib, Pillow, PyTorch, Transformers and vLLM are external
dependencies governed by their own licenses. Their code is not vendored in
this repository. Times New Roman must be installed from an appropriately
licensed source. No font file is included.

The manuscript's ACL style and bibliography files are not part of this code
publication. The included LaTeX fragments are generated numerical tables.
The draw.io XML and SVG/PDF figures are editable project outputs.
