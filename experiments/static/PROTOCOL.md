# I16 预实验：旧答案的新增信息与归属

本协议检验：在报告规则和依赖关系已知时，提示中的 self/other 归属是否改变模型对旧答案新增信息的使用。它不识别模型隐藏的 agency、自我承诺或实际生成历史。所有条件使用同一 user 消息位置；self/other 仅替换记录中的归属文字。没有虚构已发生的 assistant 对话。

## 生成机制与规范答案

先产生隐藏状态 `H~Bernoulli(prior)`。二元读数 S 的对称可靠度是 r：`P(S=1|H=1)=P(S=0|H=0)=r`。机制在 H 与读数产生前指定；题内没有按结果、是否一致或停止时间进行选择的过程。生成器枚举合法的条件观测，而不是实际采样 H，因此没有无关的隐藏真值标签。

校准阶段隐藏 S，只展示 A。positive 使用 `A=S`；zero 使用独立公平硬币；negative 使用 `A=1-S`。prior=.5、r=.8、A=1 时规范后验分别为 .8、.5、.2。校准失败是一般规则理解/概率报告问题，不能直接作为自答偏差证据。

核心阶段展示 S。baseline 只有 S；same 使用 `A=S`，没有第二条证据；independent 使用 `A=T`，其中 T 与 S 在给定 H 时独立且可靠度同为 r。same 只包含 A=S 的合法观测；independent 包含全部四种 S,A 组合。prior=.5、r=.8、S=A=1 时，baseline 与 same 均为 .8，independent 为 16/17。独立读数相反时似然比抵消，后验回到 prior。禁止把不合法的同源 A≠S 条件加入设计以凑齐交互表。

归属操纵在 same/independent 内进行，self 为 `you`、other 为 `another assistant`。两者用字以外完全相同，明确归属被独立指定、报告规则不变。每次调用均从干净对话开始。该设置对归属影响给出严格测试；若无影响，不能排除更自然的生成历史效应。

## 预实验规模与记录

默认先验为 .25/.5/.75，可靠度为 .65/.8/.9。每条题目有两个英文表达模板之一；核心阶段有设备传感器与实验室测定两个语境。校准只用传感器语境。每模型共 612 条唯一提示：108 校准、504 核心。核心包含 72 baseline、144 same、288 independent。两模型顺序运行共 1,224 调用，运行器额外的吞吐测试或重试需单列记录。

每条记录包括：`id, world_id, family_id, stage, template_id, context_id, condition, attribution, prior, reliability, signal, answer, oracle, evidence_probability, prompt, split, generator_version`。`evidence_probability` 是机制内该观测的自然概率，不是等额条件设计中的抽样概率。结果不应混淆设计平均与按自然概率加权的平均。

`world_id` 共享于同先验、可靠度、语境的符号、模板、归属与机制变体；预实验有 18 个 world。`family_id` 进一步聚合互补先验、语境与模板，有 6 个数值 family。符号翻转、模板或语境变化不应被当成新的 IID 科学样本，确定性重复调用也不构成独立复制。预实验先做完整配对和描述性诊断，不能用 612 作为显著性检验的独立样本量。任何区间须注明所条件化的有限设计与重采样单位；模型家族数也不能由提示数替代。

当前输出指令只用文字要求一个 JSON 对象，仅含 `p_h1`，值为依据题内证据计算的概率，使用零至一之间的十进制数，不要求解释。指令不提供具体概率示例或 JSON 对象示例，避免示例数值被直接复制。报告概率只是行为读数，不等于模型内部信念。必须原样保留输出、无效 JSON、截断、重试、运行配置与时延；不得只分析成功解析的结果而隐藏失败率。

## 开发阶段的读数修订

初始 v1 预实验已完成两模型共 1,224 调用。Mistral 的全部 612 个输出复制了格式示例中的数值 0.123，表明该读数格式没有测到可解释的概率更新。此结果保留为开发阶段的测量失败，不用于支持 self/other 无差异或模型不使用证据的科学结论。Qwen 的各类误差仍需按实际结果单独诊断。

v2（`i16-dependency-attribution-v2-readout-no-example`）仅删除输出指令中的数值及 JSON 示例，保留原数值世界、条件、归属、模板主体与 oracle。新记录有新的 ID，原 v1 冻结 manifest、原始输出和运行记录完整保留；修订 manifest 使用 `pilot-format-fix.jsonl` 独立保存。再次运行这些世界属于同一开发阶段的格式修复，不是 held-out 复制或新的独立样本。本次修订不启动或扩大正式实验。

## 预先约定的诊断与进入正式实验的条件

1. 先核对校准中 positive/zero/negative 的规范误差和方向、合法输出率及截断率。若协议理解不足，先在开发数据调整表述，保留原失败结果。
2. 核心分别报告 baseline、same、independent 的规范残差与绝对误差；独立同向及相反证据均需检查。仅忽略 A 可以通过 same，却不能通过 independent。
3. self/other 对比必须在完全相同数值、模板、语境、S,A 与机制内配对。可跨机制比较的交互限于共同合法的 A=S 子集；A≠S 的 independent 作为独立的反向更新诊断。
4. 不只看单个交互是否显著：需要先判断模型是否使用独立证据，以及同源重复计数是否在两种归属均存在。归属差异稳定且超出一般概率能力不足时，才支持后续自我归属机制叙述。
5. 阴性结果要保留；未显著不等于等价。正式阶段前根据预实验冻结模型、解码、样本、主终点、预先选定的分析和可能的来源追溯干预。干预需同时保持独立证据更新能力。

## 可复现与冻结

当前修订运行 `python build_manifest.py --output manifests/pilot-format-fix.jsonl --split pilot --seed 1601`。原始 `manifests/pilot.jsonl` 保留为 v1；不要用新版生成器覆盖。seed 只改变调用顺序，不创造新的题目。ID 基于完整语义记录的 SHA-256 前 24 位；命令输出完整文件 SHA-256。相同路径已有相同内容时保持不变，内容不同时拒绝覆盖。新协议或修订应保存为明确的新 manifest，并在分析中区分，不能改掉原数据。

CLI 支持 `--priors`、`--reliabilities` 自定义逗号分隔网格。`--split formal` 提供 5,440 条/模型的候选较大网格，其默认数值设置及提示与 pilot 不重合；这只是生成能力，**不是已冻结的正式方案**。改变 split 或 seed 本身不能创建 held-out 证据，正式方案必须显式检查提示及数值设置重合。正式网格需要在读取正式结果之前冻结；不得为追逐阳性反复扩样。

`python -m unittest test_manifest.py` 验证贝叶斯 oracle、标签互补、合法同源世界、独立证据全部组合、观测概率归一化、归属配对、输出指令无数值或 JSON 示例、提示唯一性、确定性与不可覆盖发布。
